Etapa 1: Estrutura Base e Setup

"Atue como um Desenvolvedor Front-end Sênior. Estou criando meu portfólio com React, Vite e Tailwind CSS. Quero uma interface 'clean', com fundo escuro (dark mode nativo) e texto claro. Escreva o código base do arquivo principal (App.jsx ou layout.jsx), definindo um contêiner centralizado e responsivo que abrigará 4 seções: Cabeçalho, Experiência, Projetos e Conquistas. Adicione comentários no código explicando onde cada componente futuro será inserido."

Etapa 2: Componente de Tooltip (Requisito Principal)

"Agora, crie um componente reutilizável chamado <HoverTooltip/> em React usando Tailwind CSS. Ele deve receber duas propriedades (props): children (o texto principal) e info (a breve explicação). A explicação deve aparecer apenas quando o usuário passar o cursor do mouse sobre o texto principal. Certifique-se de que o design seja responsivo e acessível para dispositivos móveis (ativando no toque, se possível)."

Etapa 3: Cabeçalho (Hero Section)

"Crie o componente <Hero/> para o meu portfólio. Ele deve conter meu título: 'Estudante de Engenharia da Computação & Profissional de Infraestrutura de TI'. Inclua um parágrafo de resumo informando que estou no 8º período na Uninorte em Manaus (turno da noite) e procuro oportunidades para integrar meus conhecimentos de suporte técnico com desenvolvimento de software e hardware."

Etapa 4: Experiência Profissional com Tooltips

"Crie a seção <Experience/> usando o componente <HoverTooltip/> que você criou anteriormente. Liste minha experiência como estagiário de Suporte de TI com foco nas seguintes tecnologias:

Windows Server 2022 (adicione um tooltip em 'AD' explicando: 'Active Directory: Criação e gestão de usuários do domínio')

Instalação e configuração de roteadores Unifi

Virtualização com Proxmox e Ubuntu Server

Help desk geral: configuração de pastas de rede, impressoras e gestão de reuniões no Google Meet.
Formate as informações em cards modernos."

Etapa 5: Projetos (TCC e Redes) e Conquistas

"Crie a seção <ProjectsAndAchievements/>. Ela deve ter duas partes. A primeira parte são Projetos, contendo:

Meu TCC (Foco atual): Sistema de monitoramento IoT usando ESP32, sensor de monóxido de carbono e BME280, com envio de alertas para o Telegram.

Redes/Web: Página de check-in desenvolvida em WordPress integrada ao portal cativo do painel Unifi.
A segunda parte é de Conquistas, destacando meu 2º lugar na competição de Robô Sumô da universidade. Use ícones simples ou badges do Tailwind para destacar as tecnologias."
